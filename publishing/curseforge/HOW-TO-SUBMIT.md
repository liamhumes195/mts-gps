# MTS GPS - prepared CurseForge submission

Status: prepared locally. No CurseForge project has been created or submitted by this workspace.

The `mtsgps-0.1.0.jar` beside this document is the file to upload as the Minecraft mod. The surrounding ZIP is a convenience bundle for the publisher, not a Minecraft modpack or the file to install.

1. Sign in to the [CurseForge Authors Console](https://authors.curseforge.com/#/projects/create/choose-game) with the account that should own the project.
2. Create a **Minecraft / Mods** project named **MTS GPS**. Use the summary in `project.json`, the original `icon.png`, and the contents of `description.md`. Retain the existing **All Rights Reserved** license. The suggested categories are Map and Information, Addons and Player Transport; select the available matching categories.
3. Upload **mtsgps-0.1.0.jar**. Display name: **MTS GPS 0.1.0 - Alpha**. Mark Minecraft **1.20.1**, loader **Forge**, Java **17**, environment **Client**, and release type **Alpha**. Paste `changelog.md` into the changelog field.
4. Add both required dependencies using the exact project IDs/links in `project.json`: Immersive Vehicles and its Official Content Pack. The supported dependency versions are stated in the project description.
5. Submit for moderation. Record the resulting project URL and file ID; a local bundle is not evidence of a published project. A file may remain under review before becoming public.

The icon is original project artwork, not an in-game screenshot. No screenshot or fully validated dashboard demonstration is included. The description labels this build as an alpha and distinguishes compilation/startup checks from broader in-game testing.

No source JARs, original mod assets, passwords, API tokens, local world data or Gradle caches belong in the public upload.

Reference: [Creating and submitting a project](https://support.curseforge.com/support/solutions/articles/9000197241-creating-and-submitting-a-project). The optional upload API also requires an existing project ID and an author token: [official Upload API documentation](https://support.curseforge.com/support/solutions/articles/9000197321-curseforge-api). Keep credentials in a secure account connection or local secret store, rather than this bundle or chat.
